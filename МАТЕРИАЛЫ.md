# Материалы к заданию

## SOLID

- [Real Python — SOLID Principles: Improve Object-Oriented Code in Python](https://realpython.com/solid-principles-python/) — все пять принципов на примерах кода Python
- [PEP 544 — Protocols: Structural subtyping](https://peps.python.org/pep-0544/) — как в Python объявить интерфейс без наследования (то, что используется в `base.py`/`interfaces.py`/`engine.py` этого задания)

## Liskov Substitution (кейс shapes)

- [Wikipedia — Liskov substitution principle](https://en.wikipedia.org/wiki/Liskov_substitution_principle) — тот самый пример с прямоугольником и квадратом, здесь его и разбираем

## Dependency Injection (кейс payment)

- [Python typing — Protocol](https://docs.python.org/3/library/typing.html#typing.Protocol) — официальная документация по `Protocol` из стандартной библиотеки

## pytest

- [pytest — How to parametrize fixtures and test functions](https://docs.pytest.org/en/stable/how-to/parametrize.html) — `@pytest.mark.parametrize`, которым написаны контрактные тесты этого задания
- [pytest — Skip and xfail](https://docs.pytest.org/en/stable/how-to/skipping.html) — `pytest.skip(..., allow_module_level=True)`, которым эталонные тесты пропускаются, если solution.py ещё нет
