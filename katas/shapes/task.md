## Задача

Реализуйте два класса в `solution.py`:

```python
class Rectangle:
    def __init__(self, width: float, height: float) -> None: ...
    # width и height — публичные, изменяемые атрибуты
    def area(self) -> float: ...


class Square:
    def __init__(self, side: float) -> None: ...
    def area(self) -> float: ...
```

`Rectangle.width` и `Rectangle.height` — обычные публичные атрибуты,
их можно менять напрямую (`rect.width = 5`) в любой момент независимо
друг от друга, и `area()` должен использовать актуальные значения.

## Требование, которое легко нарушить

**`Square` не должен наследоваться от `Rectangle`** — даже если
формально это компилируется и половина тестов пройдёт.

Если сделать `class Square(Rectangle)` с конструктором вида
`Square(side): super().__init__(side, side)`, то `Square` унаследует
изменяемые `width`/`height`, и появится способ создать
математически противоречивый объект: `sq.width = 5; sq.height = 10` —
это либо квадрат с разными сторонами (абсурд), либо придётся
переопределять сеттеры так, чтобы `width` и `height` держались вместе
(тогда `Square` перестаёт вести себя как `Rectangle` — вызывающий код,
который ожидает независимо настраиваемые стороны, ломается на
подстановке `Square` вместо `Rectangle`). Это и есть нарушение
Liskov Substitution Principle: подкласс не может свободно
заменить родителя.

Правильный выход — не наследовать. У `Square` нет `width`/`height`,
только `side`, и это отдельный класс.

## И наоборот: где наследование — это нормально

Дополнительно реализуйте:

```python
class ColoredRectangle(Rectangle):
    def __init__(self, width: float, height: float, color: str) -> None: ...
    # color — просто новое поле, поведение width/height/area не меняется
```

`ColoredRectangle` наследуется от `Rectangle` и проходит **ровно те же
тесты**, что и сам `Rectangle` — потому что не переопределяет и не
ограничивает унаследованное поведение, только добавляет своё поле.

Сравните с `Square` выше: проблема не в наследовании как таком, а в
том, что `Square` пытается **изменить смысл** `width`/`height`
(связать их друг с другом). `ColoredRectangle` ничего не меняет —
поэтому наследование здесь безопасно.
